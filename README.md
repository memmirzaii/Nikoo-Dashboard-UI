# 🌟 Nikoo AI Dashboard

**نسخه:** 1.0.0 (MVP)  
**شناسه قرارداد:** NIKOO-MVP-TECH-001  
**وضعیت:** در حال توسعه  
**زبان:** فارسی (RTL)  
**جهت:** راست‌چین

---

## 📋 درباره پروژه

**Nikoo AI Dashboard** یک قالب داشبورد مدیریتی مدرن، واکنش‌گرا و کاملا فارسی با پشتیبانی از راست‌چین است. این پروژه بر اساس **قرارداد فنی NIKOO-MVP-TECH-001** توسعه یافته است.

### ویژگی‌های اصلی

- ✅ **رابط کاربری فارسی** با پشتیبانی کامل RTL
- ✅ **طراحی واکنش‌گرا** برای تمام دستگاه‌ها (موبایل، تبلت، دسکتاپ)
- ✅ **سیستم طراحی مدرن** با Tailwind CSS
- ✅ **ساختار ماژولار** برای توسعه آسان
- ✅ **رابط هوش مصنوعی** (Mock در نسخه MVP)
- ✅ **سیستم ایجنت هارنس هوشمند** برای خودکارسازی فرایند توسعه
- ✅ **تضمین کیفیت** با معیارهای پذیرش کامل

## 🚀 شروع سریع

### پیش‌نیازها

- [Node.js](https://nodejs.org/) >= 18.0.0
- [npm](https://www.npmjs.com/) >= 9.0.0
- [Git](https://git-scm.com/)

### نصب

1. **کلون کردن ریپو**
   ```bash
   git clone https://github.com/memmirzaii/Nikoo-Dashboard-UI.git
   cd Nikoo-Dashboard-UI
   ```

2. **نصب وابستگی‌ها**
   ```bash
   npm install
   ```

3. **اجرای سرور توسعه**
   ```bash
   npm run dev
   ```

4. **باز کردن در مرورگر**
   ```
   http://localhost:3000
   ```

## 🤖 سیستم ایجنت هارنس

سیستم ایجنت هارنس برای خودکارسازی فرایند توسعه طراحی شده است.

### ایجنت‌ها

| ایجنت | نقش | مسئولیت |
|-------|-----|----------|
| **Controller** | مدیریت مرکزی | هماهنگی بین ایجنت‌ها |
| **Auditor** | ممیزی | بررسی فایل‌ها و امنیت |
| **UI Designer** | طراح UI | ایجاد سیستم طراحی |
| **Frontend Dev** | توسعه Frontend | توسعه کامپوننت‌ها |
| **AI Interface** | رابط AI | پیاده‌سازی Mock API |
| **QA Agent** | تضمین کیفیت | اجرای آزمون‌ها |
| **Release Agent** | انتشار | بسته‌بندی پروژه |

### اجرا کردن هارنس

```bash
# شروع هارنس
npm run harness:start

# اجرا در حالت توسعه
npm run harness:dev

# اجرا کردن ممیزی
npm run audit

# اجرا کردن آزمون‌های QA
npm run qa

# ایجاد بسته تحویل
npm run package
```

## 📁 ساختار صفحات

بر اساس **ماده ۴ قرارداد NIKOO-MVP-TECH-001**:

1. **داشبورد اصلی** (`pages/dashboard.html`)
   - نمایش شاخص‌های مدیریتی
   - کارت‌های آماری
   - نمودارها
   - فعالیت‌های اخیر

2. **مدیریت پروژه‌ها و وظایف** (`pages/projects.html`)
   - لیست پروژه‌ها
   - جست‌وجو و فیلتر
   - فرم‌های ایجاد/ویرایش

3. **دستیار هوش مصنوعی** (`pages/ai-assistant.html`)
   - صفحه گفت‌وگو
   - ارسال پیام
   - نمایش پاسخ آزمایشی

4. **مدیریت کاربران** (`pages/users.html`)
   - لیست کاربران
   - جست‌وجو و فیلتر
   - نمایش اطلاعات

5. **سیستم CRM** (`pages/crm.html`)
   - مدیریت مشتریان
   - پیگیری ارتباطات
   - گزارش‌ها

6. **پنل فروشگاه** (`pages/shop.html`)
   - مدیریت محصولات
   - سفارشات
   - گزارش‌های فروش

7. **سیستم مالی** (`pages/financial.html`)
   - تراکنش‌ها
   - گزارش‌های مالی
   - داشبورد مالی

8. **تنظیمات** (`pages/settings.html`)
   - تنظیمات رابط کاربری
   - تنظیمات ظاهری

## 🔒 امنیت

### اصول امنیتی

1. **عدم ذخیره‌سازی اسرار**: کلیدهای API و اطلاعات محرمانه در کد ذخیره نمی‌شوند
2. **اعتبارسنجی ورودی**: تمام ورودی‌های کاربر قبل از پردازش بررسی می‌شوند
3. **اسکن امنیتی**: ایجنت Auditor به صورت دوره‌ای فایل‌ها را اسکن می‌کند

### فایل .env

```
# محیط اجرا
NODE_ENV=development

# API هوش مصنوعی (در نسخه MVP غیرفعال است)
AI_API_ENDPOINT=http://localhost:8000/api/ai
AI_API_KEY=your_api_key_here

# سطح لاگ
LOG_LEVEL=info
```

⚠️ **هشدار:** فایل .env در .gitignore قرار دارد و نباید در ریپو کامیت شود.
