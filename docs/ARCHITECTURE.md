## 🎯 مقدمه

سیستم **ایجنت هارنس مهندسی هوشمند** برای پروژه **Nikoo AI Dashboard** طراحی شده است تا:
- فرایند توسعه را خودکار کند
- کیفیت کد را تضمین کند
- معیارهای پذیرش را بررسی کند
- تحویل محصول را تسهیل کند

## 🤖 ایجنت‌ها و نقش‌ها

### لیست ایجنت‌ها (بر اساس ماده ۷ قرارداد NIKOO-MVP-TECH-001)

| ایجنت | نقش | مسئولیت‌ها | وضعیت |
|-------|-----|------------|--------|
| **Controller** | مدیریت مرکزی | هماهنگی ایجنت‌ها، مدیریت وظایف | ✅ پیاده‌سازی شده |
| **Auditor** | ممیزی | بررسی فایل‌ها، وابستگی‌ها، امنیت | ✅ پیاده‌سازی شده |
| **UI Designer** | طراح UI | ایجاد Design System، توکن‌ها | ⏳ |
| **Frontend Developer** | توسعه Frontend | ایجاد کامپوننت‌ها، صفحات | ⏳ |
| **AI Interface Developer** | رابط AI | پیاده‌سازی Mock Adapter | ⏳ |
| **QA Agent** | تضمین کیفیت | اجرای آزمون‌ها، گزارش‌دهی | ✅ پیاده‌سازی شده |
| **Release Agent** | انتشار | بسته‌بندی، مستندسازی | ⏳ |

## 🔄 جریان داده‌ها

### جریان اصلی توسعه

1. **شروع هارنس** → Controller شروع به کار می‌کند
2. **ممیزی اولیه** → Auditor پروژه را بررسی می‌کند
3. **طراحی سیستم** → UI Designer Design System را ایجاد می‌کند
4. **توسعه کامپوننت‌ها** → Frontend Dev کامپوننت‌ها را می‌سازد
5. **پیاده‌سازی Mock AI** → AI Interface آداپتر Mock را آماده می‌کند
6. **اجرا آزمون‌ها** → QA Agent معیارهای پذیرش را بررسی می‌کند
7. **بسته‌بندی** → Release Agent خروجی نهایی را آماده می‌کند
8. **تحویل** → Controller گزارش نهایی را ارائه می‌دهد

## 🔒 امنیت

### اصول امنیتی

1. **حداقل دسترسی**: هر ایجنت تنها به داده‌های ضروری دسترسی دارد
2. **عدم ذخیره اسرار**: کلیدهای API در کد ذخیره نمی‌شوند
3. **اعتبارسنجی ورودی**: تمام ورودی‌ها قبل از پردازش بررسی می‌شوند
4. **اسکن امنیتی**: Auditor به صورت دوره‌ای فایل‌ها را اسکن می‌کند
